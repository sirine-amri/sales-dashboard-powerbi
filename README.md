# Sales Performance Dashboard (Power BI)

[English](#english) | [Deutsch](#deutsch)

---

## English

### Objective
Interactive Power BI dashboard analyzing sales performance by year, category, segment, product and state.

### Dashboard content
- KPIs: Total Sales, Total Profit, Profit Margin, YoY Growth, Total Orders
- Monthly evolution of sales and profit
- Sales by segment, category and year
- Top 10 products and Top 10 states
- Filters: year and category

### Tools
Python (pandas, seaborn), Power BI, DAX

### Project workflow
1. Data cleaning and exploration in Python (pandas) - see `notebooks/sales_analysis.ipynb`
2. Visualizations in Python (seaborn)
3. Interactive dashboard in Power BI

## Deutsch

### Ziel
Interaktives Power-BI-Dashboard zur Analyse der Verkaufsleistung nach Jahr, Kategorie, Segment, Produkt und Bundesstaat.

### Inhalt des Dashboards
- Kennzahlen: Gesamtumsatz, Gesamtgewinn, Gewinnmarge, Umsatzwachstum (YoY), Anzahl der Bestellungen
- Monatliche Entwicklung von Umsatz und Gewinn
- Umsatz nach Segment, Kategorie und Jahr
- Top-10-Produkte und Top-10-Bundesstaaten
- Filter: Jahr und Kategorie

### Werkzeuge
Python (pandas, seaborn), Power BI, DAX

### Projektablauf
1. Datenbereinigung und -analyse mit Python (pandas) - siehe `notebooks/sales_analysis.ipynb`
2. Visualisierungen mit Python (seaborn)
3. Interaktives Dashboard in Power BI
